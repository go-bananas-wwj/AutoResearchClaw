三个布局方向

左边栏都是项目列表（一个项目一篇论文），区别在右侧怎么组织。点进去看效果，然后告诉我选哪个、或怎么混搭。

A · 项目 + Tab（Codex 经典式）

点进项目后右侧分「总览 / 交互 / 管理」三个 tab。交互 tab 是对话流，门控卡片插在对话流顶部。结构最清晰，各归其位；代价是多一次 tab 切换。

B · 对话流即主页（无 Tab）

点进项目就是一条对话流：进度卡、门控卡、论文批注卡全部内联在对话里，没有 tab。最贴近"对话驱动科研"的理念；代价是产物浏览、设置类操作藏得比较深（折叠在顶部上下文条里）。

C · 三栏 IDE 式

左项目、中对话、右上下文面板（门控操作 + 进度 + 论文状态 + 产物文件 + 硬件开销）。信息一屏全收、不用切换；代价是屏幕窄时拥挤，右栏信息密度高。
